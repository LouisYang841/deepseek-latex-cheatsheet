DeepSeek 网页版 LaTeX 命令速查表

逆向自 chat.deepseek.com 前端（commit 29e61c85，2026-09）· KaTeX KaTeX 0.16.22 + MicroTeX WASM 双层渲染

KaTeX 层（HTML 渲染）1020 个命令公式主体走这里：清晰、随主题、可选中。只要整条公式里每个命令它都认识，就用这层。
MicroTeX WASM 层（SVG 渲染）166 个独有命令整条公式中只要有一个 KaTeX 不认识的命令，整条落到这层，以排版引擎风格渲染成 SVG。
  • 两条公式想保持观感一致就别混层：混进一个 \ovalbox，整条公式都会变成 SVG 版式。
  • WASM 层藏着一整套 dvips/Crayola 色名（如 \textcolor{wildstrawberry}{...}）——KaTeX 不认识这些色名，正好整条转 SVG 上色。
  • 表格类玩法在 WASM 层：tabular + multirow / multicolumn / cellcolor / hdotsfor。
  • 两层都不认识的命令 → 显示原文并上报。点击色块可复制命令。
判定方法：KaTeX 层 = katex chunk 命令字面量；WASM 层 = MicroTeX 源码词汇 ∩ wasm 二进制字符串。个别条目可能因版本差异失效；WASM 层命令以实测为准。
